# Acknowledgements

## LearnHarness

The learning method of Ranviera is inspired by LearnHarness (https://github.com/amosblomqvist/learnharness), an open source learning application licensed under the GNU Affero General Public License 3.0. The inspiration covers the idea of an agent that measures what a person holds, plans a route, teaches one reasoning step at a time and sets practice, and the idea of a graph of propositions and arguments that grows from the person's own sessions and notes. The method was also described in the public talk 'Agent Harness for Learning Things' (YouTube, 23 October 2026).

Ranviera contains no code, prompt text, documentation text or test text from LearnHarness. It reimplements the behaviour of LearnHarness in a clean room and is licensed under the Apache License 2.0. Its learning data folder follows the folder layout of LearnHarness data format version 1 so that each application can read the learning data folder of the other. Ranviera is not affiliated with LearnHarness or with its authors, and this acknowledgement implies no licence, permission or endorsement from them.
