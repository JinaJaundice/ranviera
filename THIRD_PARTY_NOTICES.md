## Tools that are bundled or used to build

The installers contain Electron, which is licensed under MIT, and the Chromium and Node.js code inside it, which carry their own licences. Electron ships them in the files LICENSE and LICENSES.chromium.html in the application folder.

The compiler executable is built with PyInstaller, which is licensed under GPL-2.0-or-later with an exception that allows a program built with it to be distributed under any licence. PyInstaller is a build tool and no part of it other than its bootloader is included in the executable.
